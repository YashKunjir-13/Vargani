# Frontend Applications Directory (`frontend/apps/`)

This directory contains all client-facing frontend applications in the **PautiPustak** workspace.

## Directory Structure

```text
frontend/apps/
└── mobile-app/               # Cross-platform Flutter mobile application (Material 3, Riverpod, Drift)
```

## Running Applications

- **Mobile Client**:
  ```bash
  cd frontend/apps/mobile-app
  flutter pub get
  flutter run
  ```
