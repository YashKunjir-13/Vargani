# Domain Glossary

| Term | Meaning |
|---|---|
| Organization | Independent tenant using Pauti Pustak. |
| Membership | Relationship connecting a user to an organization and role. |
| Event | Financial and operational scope such as a Ganpati festival or social event. |
| Volunteer | Person assisting the organization, with or without a login. |
| Collector | Volunteer or member assigned to collect contributions. |
| Contributor | Individual, family, shop, society, sponsor, or institution contributing value. |
| Contribution Bill | Personalized request issued to a contributor for an event. |
| Collection | Recorded payment attempt or manual receipt of money pending or confirmed. |
| Contribution | Canonical confirmed event income record. |
| Receipt | Immutable proof generated for a confirmed payment. |
| Settlement | Handover and reconciliation of collected cash or instruments. |
| Expense | Event-related spending request and approval record. |
| Financial Account | Cash, bank, UPI, or other account tracked by finance. |
| Ledger | Append-only double-entry source of financial truth. |
| Tenant Context | Active organization and optional event context. |
| Idempotency Key | Stable key preventing duplicate effects when a request is retried. |
| Official Document | Backend-generated bill, receipt, or report with immutable identity. |
