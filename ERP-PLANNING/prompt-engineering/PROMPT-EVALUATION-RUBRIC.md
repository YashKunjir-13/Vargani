# Prompt Evaluation Rubric

Score 0–5 for each dimension:

1. Requirement coverage
2. Scope control
3. Technical correctness
4. Security/privacy completeness
5. Tenant and financial correctness
6. Testability
7. Repository awareness
8. Dependency awareness
9. Failure and rollback handling
10. Output clarity
11. Token efficiency
12. Auditability

Approval requires no dimension below 3 and an average of at least 4.
