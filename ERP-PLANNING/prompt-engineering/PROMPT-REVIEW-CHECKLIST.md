# Prompt Review Checklist

- [ ] One clear task objective
- [ ] Approved roadmap task ID
- [ ] Mandatory context paths
- [ ] Scope and exclusions
- [ ] Existing-code inspection
- [ ] Business rules and invariants
- [ ] File/service boundaries
- [ ] Security and tenant rules
- [ ] Data migration and rollback
- [ ] Idempotency/concurrency/failure handling
- [ ] Audit and observability
- [ ] Required tests and commands
- [ ] Stop conditions
- [ ] Definition of Done
- [ ] Structured final report
- [ ] No secrets or real production data
- [ ] No request to handwrite generated files
