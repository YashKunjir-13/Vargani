# Context Management

## Layer 1 — Global

Product context, architecture bible, business rules, standards.

## Layer 2 — Domain

Only the bounded-context reference and contracts required for the selected task.

## Layer 3 — Task

Roadmap row, story, acceptance criteria, dependencies, exact output scope.

## Layer 4 — Live repository

Current files, interfaces, migrations, tests, Git diff, and tool versions.

Avoid pasting the entire repository or all planning documents into every session. Provide the smallest complete context that preserves correctness.
