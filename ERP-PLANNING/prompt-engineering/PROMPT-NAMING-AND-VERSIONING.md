# Prompt Naming and Versioning

Pattern:

`PP-<STAGE>-<TASK>-v<MAJOR>.<MINOR>.<PATCH>-<slug>.md`

- Patch: wording or clarity with no scope change.
- Minor: additional non-breaking validation, test, or output.
- Major: architecture, contract, ownership, scope, or dependency change.

Statuses: Draft, In Review, Approved, Executed, Superseded, Archived.
