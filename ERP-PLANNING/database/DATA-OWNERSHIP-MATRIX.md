# Data Ownership Matrix

| Data | Owner |
|---|---|
| User identity and sessions | Identity service |
| Organization, membership, role | Tenant service |
| Event lifecycle | Event service |
| Volunteer and assignment | Volunteer service |
| Contributor identity | Contributor service |
| Bill, collection, contribution, receipt | Contribution service |
| Provider payment state | Payment service |
| Account, expense, transfer, ledger | Finance service |
| Document metadata and PDF | Document service |
| Delivery attempts | Notification service |
| Read models and exports | Reporting service |
| Immutable audit evidence | Audit service |
