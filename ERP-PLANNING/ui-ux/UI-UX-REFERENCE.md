# UI/UX Reference

## Principles

- Mobile-first for collectors; responsive tablet/web for committees and auditors.
- Marathi, Hindi, and English from the foundation.
- Clear loading, empty, error, offline, conflict, and permission states.
- No hidden destructive actions.
- Money, dates, statuses, and outstanding balances are visually unambiguous.
- Accessibility includes keyboard navigation, semantics, contrast, text scaling, and screen-reader labels.

## Required design artifacts

- Screen inventory
- User flows
- Low-fidelity wireframes
- High-fidelity prototypes
- Design tokens and components
- Responsive behaviours
- Form and validation rules
- Accessibility checklist
- Usability findings
